# 📅 Date Formatter in JavaScript

This project demonstrates how to work with JavaScript's `Date` object and format dates in different styles.  
It includes functions to display the current date and time, as well as custom formatting options.

---

## 🚀 Features
- Display the **current date and time**.
- Format dates in **MM/DD/YYYY** style.
- Format dates in **long form (Month Day, Year)** style.

---
